This directory hosts all the source code and resources of the Minimum Viable Product.
----

You can enable automatic code formatting through a pre-commit Git hook by installing Husky. NOTE: Husky requires Git to be installed.

To install Husky, run this in the PowerShell:
    .\scripts\Install-Husky.ps1
If the execution policy blocks it, try:
    powershell -ExecutionPolicy Bypass -file .\scripts\Install-Husky.ps1
